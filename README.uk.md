## Що це

Двоекранний трекер витрат для Android, побудований навколо одного вимірюваного
показника: **менше двох секунд від тапу по іконці до збереженої транзакції.**

Це число і є всім дизайном. Пад відкритий одразу при запуску — немає кнопки
«додати», яку треба натиснути перед тим. П'ять найчастіших категорій стоять під
великим пальцем. Сума, категорія, зберегти. Кожну іншу фічу звіряли з питанням,
чи додає вона клік на цьому шляху; більшість додає — тому більшості тут немає.

- **Два екрани.** Ввід і історія.
- **Калькулятор просто на паді.** Чотири дії, зліва направо, без пріоритету
  операцій — бо «два оцих і одне оте» трапляється біля каси, а не в голові.
- **Доходи** рівно для одного: показати різницю за поточний місяць. Без
  накопичувального балансу.
- **Куди пішли гроші** — категорії за сумою, а не кільцева діаграма.
- Нотатки, резервна копія і CSV, українська та англійська, скасування видалення.

## Чого тут свідомо немає

| Немає | Чому |
|---|---|
| Синхронізація з банками, хмара | Потребує мережі, серверів і акаунтів. Знищує все позиціонування одним рухом |
| Реєстрація, акаунт, вхід | Немає сценарію, де це щось дає користувачу |
| Аналітика, телеметрія, крашлоги | Ми свідомо погоджуємось бути сліпими |
| Будь-яка залежність, що ходить у мережу | Перевіряється до того, як потрапить у `pubspec.yaml` |
| Діаграми | Питання звучить «куди пішли гроші»; відсортований список відповідає швидше |
| Конвертація валют | Ми офлайн, курсів узяти нізвідки |
| Реклама | — |

Реліз-маніфест оголошує один дозвіл — `VIBRATE`. Дозволу `INTERNET` немає, як
немає й мережевої залежності: застосунок не може нічого нікуди надіслати,
навіть якби хтось дописав код, який намагається.

## Архітектура

Свідомо пласка — для двох екранів шари абстракцій коштують більше, ніж
повертають.

```
lib/
  db/            Drift: таблиці, DAO, міграції
  models/        доменні моделі
  repositories/  транзакції, категорії, налаштування
  providers/     Riverpod
  services/      резервна копія, CSV, шеринг
  ui/            input · history · sheets · settings · onboarding · common
  theme/         токени дизайн-системи як Dart-константи
  l10n/          ARB-файли
```

Єдине правило: UI ніколи не звертається до Drift напряму, тільки через
репозиторій.

Два рішення, які було б болісно міняти згодом: **гроші — `int` у мінорних
одиницях** (`85.00` зберігається як `8500`, бо `0.1 + 0.2 != 0.3`, і користувач,
який побачить, що сума рядків не сходиться з підсумком, матиме рацію не
довіряти застосунку) і **дата зберігається двічі** — `createdAtUtc` упорядковує
записи всередині дня, `localDateKey` вирішує, якому дню запис належить, і одне
поле не здатне робити обидві роботи, коли міняється часовий пояс.

**Стек:** Flutter 3.47 · Riverpod · Drift/SQLite · `minSdk 24` · `targetSdk 36`

## Збірка

```bash
git clone https://github.com/yevhenmyronov/qvas.git
cd qvas
flutter pub get
flutter run
```

Релізна збірка відкочується на debug-ключ, якщо не скопіювати
`android/key.properties.example` у `android/key.properties` і не заповнити.

## Тести

```bash
flutter test
```

140 тестів: арифметика грошей, ключі дати при зміні часового поясу, семантика
калькулятора, повний цикл резервної копії, екранування CSV і golden-тести, що
фіксують сім станів екранів.

Два з них — лінтери, і саме їх варто вкрасти собі. `lint_tokens_test.dart`
валить збірку, якщо шістнадцятковий колір трапився поза `theme/tokens.dart`,
якщо радіус написаний числом або якщо шторку відкрито повз єдиний спільний
хелпер. `lint_durations_test.dart` вимагає, щоб кожна тривалість анімації йшла
через `AppDurations.of`, який повертає нуль при увімкненому системному
«Прибрати анімації». Кожне правило з'явилося після того, як відповідний дубль
уже стався.
