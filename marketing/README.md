# Матеріали для презентації

Знімки екранів для сторінки Play і презентацій — два набори:

- `screenshots/` — українська, гривня
- `screenshots-en/` — англійська, долар

Обидва зняті з **демо-застосунку** `com.qvas.app.demo`: окрема збірка з власною
базою. Робоча база догфудингу (`com.qvas.app`) при цьому не відкривається взагалі.

## Що знято

| Файл | Що показує |
|---|---|
| `01-input-empty` | Екран 1 у спокої: пад відкритий одразу, п'ять закріплених категорій |
| `02-input-ready` | Сума й категорія зійшлись — «Зберегти» залите зеленим |
| `03-history` | Екран 2: «Різниця», підсумки місяця, стрічка з нотатками |
| `04-breakdown` | Розбивка витрат за категоріями (шторка з панелі підсумків) |
| `05-quick-edit` | Шторка редагування: сума, категорія, нотатка, дата |
| `06-filter-category` | Фільтр за категорією і сума по ній |
| `07-income` | Режим доходу: зелені цифри, власний набір категорій |
| `08-calculator` | Калькулятор просто на паді: `800 + 400` під сумою |
| `09-settings` | Налаштування: валюта, мова, резервна копія, CSV |
| `10-categories` | Повний список категорій, закріплення й пошук |
| `contact-sheet` | Усі знімки в один ряд, для швидкого перегляду |

В українському наборі нумерація трохи інша (там `05` — фільтр, `06` —
редагування), решта збігається.

## Як перезняти

Демо-дані описані в [`tool/seed_demo.py`](../tool/seed_demo.py) — два набори,
`uk` і `en`. Суми, нотатки й дати задані списком, не випадкові; долари не є
перекладом гривень, кожен набір має власний порядок сум. Дати рахуються від
сьогоднішнього дня, тож верхня група стрічки завжди «Сьогодні».

```bash
flutter build apk --debug --target-platform android-arm64
adb install -r build/app/outputs/flutter-apk/app-debug.apk
adb shell monkey -p com.qvas.app.demo -c android.intent.category.LAUNCHER 1
adb exec-out run-as com.qvas.app.demo cat app_flutter/qvas.sqlite > qvas.sqlite
python tool/seed_demo.py qvas.sqlite en
adb shell am force-stop com.qvas.app.demo
adb push qvas.sqlite /data/local/tmp/
adb shell "run-as com.qvas.app.demo sh -c 'rm -f app_flutter/qvas.sqlite-wal app_flutter/qvas.sqlite-shm; cp /data/local/tmp/qvas.sqlite app_flutter/qvas.sqlite'"
```

Далі — знімки: `adb exec-out screencap -p > файл.png`.

Мова застосунку перемикається разом із даними, через `locale_override` у базі:
руками в налаштуваннях нічого міняти не треба. Вбудовані категорії
перекладаються самі за `name_key`, свої (Підписки / Subscriptions,
Книги / Books) задані в наборі.

**Чому саме debug-збірка.** `run-as` працює лише з debuggable-застосунком —
це єдиний спосіб покласти готову базу без рута. Заразом
`android/app/build.gradle.kts` дає debug-збіркам суфікс `.demo`, тож демо
ніколи не переписує робочий застосунок.

**Якщо adb каже `more than one device`** — телефон видно і через IP, і через
mDNS. Лікується явним вибором: `adb -s 192.168.0.101:37487 ...`.

## Що варто знати перед відправкою в Play

- **Годинник у статусбарі — час зйомки.** HyperOS ігнорує `sysui_demo`, тому
  рівні 9:41 на всіх знімках не вийшли; заряд і сповіщення підмінити вдалось.
  Демо-режим статусбара після зйомки вимкнено (`sysui_demo_allowed = 0`).
- Знімки зроблені на POCO 2511FPC34G, 1268×2756. Play приймає такі як є;
  feature graphic (1024×500) тут немає.
- Рамки пристрою в макетах — iPhone. Для презентації байдуже, для сторінки
  Play варто взяти Android-рамку або обійтись без рамки.
